# MIG-015-01 — Contract contribution calculator

Status: DONE for the pure calculation; the analytics query, rate cards, timesheets and any API/UI remain
Intent: Port the source's contract-contribution metric so firm practice analytics can report contracted fee less lifetime approved-time standard value with the source's exact arithmetic and its availability rules.
Source commit and files: `nirzaf/AuditSphere@64713e808d165b4ef91ea4be4979e0f98fb2def3`; `src/AuditSphereOps.Application/Practice/ContractContributionCalculator.cs`, `src/AuditSphereOps.Domain/Shared/Kernel.cs` (`MoneyPolicy.Normalize`), `tests/AuditSphereOps.Domain.Tests/ContractContributionCalculatorTests.cs`.
Destination commit and files: `packages/server/src/modules/practice/analytics.ts` (new), `packages/server/src/index.ts`, `packages/server/src/modules/practice/README.md`, `fixtures/characterization/practice-analytics.json` (new), `tests/practice-analytics.test.ts` (new), `tests/characterization.test.ts`, `scripts/migration/differential.mjs`.
Existing T-task links: T143 (realization), T146 (firm P/L); C33; MIG-015.
Dependencies: T023 decimal primitive (`Decimal6`, `roundHalfEvenDiv`); MIG-003 differential harness.
Scope: a pure calculator and its validator — no database, clock, network or UI. Per-row `minutes × rate / 60` is summed as an exact rational over the shared denominator 60 and rounded once, half-to-even, to six decimals, matching `MoneyPolicy.Normalize` applied after the C# `decimal` sum. The validator fails closed on a negative fee, blank currency, a negative/fractional/non-integer minute count, a null or negative captured rate, and any currency that is not ordinally equal to the contracted currency.
Non-goals: `PracticeAnalyticsQuery` (engagement economics rows, department utilization, milestone performance), persistence, rate cards, timesheets, budgets, an API endpoint, a UI screen, and any relabelling of the metric.
Current behavior and invariants: the source returns `null` — not zero — when the figure is unavailable, so a missing rate or a foreign currency can never read as "full contribution"; the destination preserves that. The exposed names are `lifetimeStandardValue` and `feeLessStandardValue`, matching the source record, so D07's requirement to state the contracted-fee minus hours×charge-out-rate basis rather than call it payroll-cost profit is carried in the type itself. An empty approved-time list is valid and yields a zero standard value, as the source `Sum` does.
Proposed contract / schema change: none; no table, route or browser contract changes.
Permission and transaction boundary: none required — the calculator is pure and performs no reads or writes; any future query that feeds it must still enforce firm-scoped practice authority.
Historical data / document impact: none; no records are created, read or altered.
Implementation steps: read the source calculator, `MoneyPolicy` and the source domain test; ported the validator and calculator onto `Decimal6`; exported from the server package; extracted the five source-quoted cases into a characterization fixture; wired the fixture into the differential harness and the fixture self-check.
