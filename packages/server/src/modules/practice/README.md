### Invoice-payment journal integrity

Each recorded invoice payment has one immutable `InvoicePaymentLedgerPosting` relation to a posted firm journal. The journal must debit account 100 cash/bank and credit account 120 receivables for the exact amount on the UTC payment date. PostgreSQL requires the posting link at transaction commit and rejects link edits or direct payment inserts without one. This supports a payment against one invoice; multi-invoice allocation and cleared-payment state remain separate workflow requirements.
